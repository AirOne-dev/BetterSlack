Plugin API

Everything a mod is handed

A plugin is an ES module that exports start(api). This page lists all entries on that object, read straight from the TypeScript, so it cannot fall behind the code. Everything that can run in a browser runs here on the page; everything that needs Slack says so.

export default { start(api) { api.ui.toast('Hello from a mod'); }, };

Live on this page

These are not mock-ups. The page imports the same modules a mod imports — the component kit, the readme renderer, Code Highlight's tokeniser, the theme builder's role derivation — so what you see is what runs inside Slack.

api.ui.kit(document)

Thirteen primitives, prefixed sm- so the stylesheet is safe anywhere. This is what a mod uses in a window of its own, where there is no Slack stylesheet to borrow from.

renderMarkdown(source)

What the panel runs on a mod's README. It escapes first and drops a javascript: URL, which is why a readme can be rendered at all.

highlight(code, language) · detect(code)

Code Highlight's own two functions. Slack sends a code block as plain grey text with nothing saying what is in it, so the language is worked out from the code — and left alone when the guess is not confident.

derivePalette(background, accent)

Two colours in, twelve roles out — the derivation the theme builder runs before it writes a stylesheet. Drag either one and watch the rest move.
