# Midnight

A deeper, cooler dark theme. Overrides Slack's design tokens rather than its class names, so it keeps working across Slack updates.

- A deeper, cooler dark than Slack’s: near-black surfaces, blue-leaning greys.
- It overrides Slack’s design tokens rather than its class names, so a Slack update that renames a class does not break it.
- Small enough to read in one sitting if you want to fork it into your own.
