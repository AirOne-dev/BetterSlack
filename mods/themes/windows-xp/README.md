# Windows XP

Slack in Luna, the look Windows XP shipped with in 2001, with every colour taken from Microsoft's own values rather than from memory.

- **The title bar** is Slack's top bar, in Luna's fifteen-stop blue gradient, with the search box as an XP text box.
- **The taskbar** stands on its side as the rail: Slack's tabs are taskbar buttons, and the one you are on is pressed in. The BetterSlack button at the bottom is the green **start** button, and it still opens the menu that runs everything else.
- **Explorer's task pane** is the channel sidebar: each section is a task box with its white-to-blue header and round chevron, the workspace name is the dark-blue "special" box, and the open conversation is a selected item, white on blue.
- **Windows**: Slack's dialogs, Preferences and BetterSlack's own panel get a blue caption, the red close button and a putty body. Push buttons have the dark-blue edge, the orange ring under the pointer and the blue ring on the default. Tabs have the orange cap.
- **Balloons**: every tooltip is XP's yellow notification balloon, with a black edge, round corners and a tail. Menus are white with the blue highlight.
- **The rest**: XP's 17px scroll bars with arrow buttons and a gripped thumb, Tahoma throughout, code blocks as the command prompt, and the command palette dressed as the start menu.

## Settings

- **Colour scheme**: Blue (the default), Olive Green or Silver, the three schemes XP shipped. The start button stays green in all three, as it did.
- **Aero glass**: XP never had it (it came with Vista), but it is what everyone remembers next to it. When it is on, Bliss is drawn behind the client, and the title bar, the rail and the task pane become Windows 7's blurred sky glass, with black caption text glowing white.
- **Message text**: 11px is Tahoma 8 point, exactly what XP used, and small on a modern screen. 13px is the default; 15px is Slack's own size.

## Its own icon and boot screen

While the theme is on, BetterSlack wears its mark the way XP drew things -- glossy, outlined, inside a Luna window -- in the Dock on macOS, from the next start (switching the theme on offers to relaunch). And the screen that covers Slack while it starts is XP's boot screen: black, the mark, and the three blue blocks sliding along their track.

## Works with every plugin

The theme repaints Slack's design tokens, and BetterSlack's plugins read those same tokens. The member column, the account strip, History, the palette and every dialog a mod opens all follow the scheme without the theme having to name them.

## What is not in it

No Microsoft file is shipped. Bliss, the icons, the Windows flag and the theme bitmaps are copyrighted. So:

- the wallpaper is drawn with gradients, and every glyph (the tick, the arrows, the chevron) is a few lines of SVG written for this theme;
- Tahoma and Trebuchet MS are named, never bundled. Both come with macOS and Windows.

The values come from:

- Windows XP's default system colours, which Microsoft's open-source WPF Luna theme repeats;
- XP.css and the winXP reconstruction (both MIT);
- Microsoft's 2001 *Windows XP Visual Guidelines*.
