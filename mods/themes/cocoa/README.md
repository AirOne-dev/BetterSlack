# Cocoa

A warm, low-contrast light theme: cream paper, cocoa text, generous 18px corners and soft shadows instead of borders. Easy on the eyes for a long day of reading.

- Cream paper, cocoa-brown text, and a teal accent kept quiet enough to read against.
- Borders are replaced by soft shadows, and corners are 18px, so nothing on screen has a hard edge.
- Contrast is deliberately lower than Slack’s own light theme: easier over a long day, and not the theme to pick for a bright room.
