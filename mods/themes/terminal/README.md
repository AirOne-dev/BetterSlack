# Terminal

Slack as a phosphor terminal: monospace everywhere, zero rounded corners, hairline borders, amber and green on near-black. Square avatars included.

- Monospace everywhere, no rounded corners, hairline borders: Slack as a phosphor terminal.
- Amber and green on near-black, with square avatars to match.
- All three colours are settings, under the theme in the panel: the phosphor, the attention colour and the background. Everything derived from them follows — the twenty-five tints and Slack's legacy tokens alike.
- Long messages read differently in a monospace face — try it for a day before deciding.
