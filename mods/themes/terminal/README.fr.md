# Terminal

Slack en terminal à phosphore : monospace partout, aucun coin arrondi, bordures d'un cheveu, ambre et vert sur presque-noir. Avatars carrés compris.

- Monospace partout, aucun coin arrondi, bordures d’un cheveu : Slack en terminal à phosphore.
- Ambre et vert sur presque-noir, avatars carrés pour aller avec.
- Les trois couleurs sont des réglages, sous le thème dans le panneau : le phosphore, la couleur d’alerte et le fond. Tout ce qui en dérive suit — les vingt-cinq teintes comme les jetons hérités de Slack.
- Un message long ne se lit pas pareil en chasse fixe — essayez une journée avant de trancher.
