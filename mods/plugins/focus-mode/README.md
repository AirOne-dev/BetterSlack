# Focus Mode

Press Cmd/Ctrl+Shift+F to fold away the sidebar, the rail and the top bar, leaving just the conversation on a narrower, centred column. Press again to bring it all back.

- ⌘⇧F (Ctrl+Shift+F elsewhere) folds away the rail, the sidebar and the top bar and centres the conversation in a narrower column.
- A small strip stays on screen to remind you how to get out. Press again and everything comes back where it was.
- It is pure CSS behind a class on the document, so there is nothing running while it is off.
