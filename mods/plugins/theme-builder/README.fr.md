# Theme Builder

Un atelier de thème dans sa propre fenêtre, avec le vrai Slack à côté en guise d'aperçu : deux couleurs en deviennent douze réparties sur les quatre familles de jetons, pointez n'importe quoi dans l'application pour voir et modifier les jetons qui le peignent, cherchez parmi toutes les couleurs du client, et ajoutez votre CSS par-dessus.

- Un atelier dans sa propre fenêtre, avec le vrai Slack à côté en guise d’aperçu : ce que vous changez repeint le client en direct.
- Deux couleurs en deviennent douze, écrites dans les quatre familles de jetons de Slack ; partez de zéro ou d’un thème que vous avez, dont les couleurs sont relues dans la palette.
- Pointez n’importe quoi dans Slack pour voir les jetons qui le peignent, survolez une couleur pour encadrer tout ce qu’elle touche, cherchez parmi les ~525 jetons de couleur du client, et ajoutez votre CSS par-dessus.
- Tant qu’il est ouvert, vos propres thèmes sont mis de côté : ce que vous voyez est ce que vous construisez. Le fermer les remet.
