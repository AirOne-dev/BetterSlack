# Copy Message Link

Copie le lien permanent d'un message en un clic, depuis les actions au survol, au lieu d'ouvrir le menu et d'y chercher « Copier le lien ». Confirme par une petite notification.

- Un bouton lien dans les actions au survol, à la place de l’aller-retour par le menu de débordement.
- Copie le même lien permanent que Slack, et le confirme par une petite notification.
