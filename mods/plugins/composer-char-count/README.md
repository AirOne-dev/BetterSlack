# Composer Character Count

Shows a live character count under the message composer, and warns before you cross Slack's 4000-character limit and get split into two messages.

- A live count under the composer, out of the way until it matters.
- Slack splits anything past 4000 characters into two messages without warning; this warns first.
- The threshold is yours to set, and it can be shown all the time rather than only near the limit.
