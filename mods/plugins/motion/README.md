# Motion

Slack, with the frames in between: conversations that fade in instead of snapping, dialogs and menus that arrive on a spring, reactions that pop, and hover and press feedback on everything you point at. It covers the components the plugin API hands out too, so every mod's own interface moves with the app. Five families you can switch off one by one, and speed and amplitude on dials.

- Conversations fade in instead of snapping. Dialogs and menus arrive on a spring. Reactions pop. Everything you point at answers.
- It covers the components the plugin API hands out, so every mod’s own interface moves with the app rather than sitting still inside it.
- Five families — views, panels, hover, press, arrivals — each switchable on its own, with speed and amplitude on dials.
- It ignores the system’s reduce-motion preference on purpose: switching this on is the request.
