# User Inspector

Montre tout ce que l'API de Slack sait d'un membre — rôles, fuseau horaire, présence, Ne pas déranger, champs personnalisés et toutes les tailles d'avatar — en sections supplémentaires dans son profil, dans le style de Slack. En lecture seule ; rien ne quitte votre machine.

- Des sections supplémentaires dans le profil d’un membre : rôles, fuseau horaire et heure locale, présence, Ne pas déranger, champs personnalisés, et toutes les tailles d’avatar conservées par Slack.
- Il porte les classes de Slack : il suit donc le thème que vous avez.
- En lecture seule. Tout vient de l’appel d’API que fait le client de Slack lui-même, et rien ne quitte votre machine.
