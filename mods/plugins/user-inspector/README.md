# User Inspector

Shows everything Slack's API knows about a member — roles, timezone, presence, do-not-disturb, custom fields and every avatar size — as extra sections inside their profile, styled like Slack's own. Read-only; nothing leaves your machine.

- Extra sections inside a member’s profile: roles, timezone and local time, presence, do-not-disturb, custom fields, and every avatar size Slack stores.
- It wears Slack’s own classes, so it follows whatever theme you are on.
- Read-only. Everything comes from the API call Slack’s own client makes, and nothing leaves your machine.
