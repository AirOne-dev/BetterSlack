# Quote Reply

Adds a Reply button to the hover actions on a message. It drops a link to that message into the composer as a single "." and focuses it, so your answer posts in the channel with Slack's own preview of the message you are answering.

- A Reply button in the hover actions puts a link to that message in the composer and focuses it.
- The link goes in as a single "." so the composer stays readable; when you send, Slack renders its own preview of the message you are answering.
- The answer lands in the channel, not in a thread — which is the point.
