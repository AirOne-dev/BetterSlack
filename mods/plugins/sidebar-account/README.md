# Sidebar Account Strip

Your avatar, name and availability at the bottom of the channel sidebar, the way Discord and other chat apps put them; clicking it opens Slack's own account menu.

- Your avatar, name and availability at the bottom of the channel sidebar, where Discord and most chat apps put them.
- Clicking it opens Slack’s own account menu, so nothing behaves differently from the button in the rail.
- The status you set for yourself is shown in place of the availability word, emoji and all — including a custom workspace one, drawn as its own image.
- Availability is read from the client, not polled: Slack’s API lags its own UI by up to a minute after the window comes back to the front.
