# Full Links

Garde les liens longs entiers. Slack raccourcit une URL à son domaine suivi de points de suspension — dans les messages que vous lisez comme dans ceux que vous envoyez, puisque le libellé court est enregistré dans le message. Ce mod répare les deux : il rétablit ce qui est à l'écran, et empêche le raccourcissement au moment où vous collez.

- Slack raccourcit une URL longue à son domaine suivi de points de suspension. Ce mod remet l’adresse entière là où elle est affichée.
- Il empêche aussi le libellé court d’être créé quand vous collez : la forme tronquée est enregistrée dans le message, donc votre destinataire voit le même moignon que vous.
- Un lien que quelqu’un a délibérément intitulé n’est pas touché : le mod ne s’occupe que de ceux que Slack a marqués comme tronqués.
