# Full Links

Keeps long links whole. Slack shortens a long URL to its host and an ellipsis -- in the messages you read, and in the ones you send, since the short label is stored in the message itself. This puts both back: it restores what is on screen, and stops the label being made when you paste.

- Slack shortens a long URL to its host and an ellipsis. This puts the whole address back where it is drawn.
- It also stops the short label being made at all when you paste: the truncated form is stored in the message, so the person reading it sees the same stub you did.
- A link somebody deliberately labelled is left alone — the mod only touches the ones Slack marked as truncated.
